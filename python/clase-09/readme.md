## Juego PyGame

Este juego es una reversion del juego comenzado en la clase 07, hicimos una version Argenta de Terminator, donde la IA se revela y crea robots para perseguir a la resistencia y tambien un virus donde parte de la poblacion es convertida en zombie.
El lider de la resistencia Juancito Connor sera el encargado de enfrentarse a RedCielo para librar al pais del caos y el terror.
